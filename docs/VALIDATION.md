# 版本与验证记录

## 2026-10-19 · v12

环境：Xiaomi 15、Android 16、HyperOS 3.0.307.0；非小米 Windows 台式机运行小米互联服务。贴纸选购规格为 NTAG213 25mm 白标，可写 NDEF。

- 首次仅写自定义 URI，手机能读到内容，但系统 NFC 分发器拒绝未知 scheme，应用未启动。
- v11 保留 URI，并追加指向应用包名的 Android Application Record（AAR）。真实碰贴纸后，NFC 入口验证通过；该修复已在设备上确认。
- 真实原图传输后，程序可能未捕获短暂完成状态，导致下次碰触被旧的等待状态阻塞。v12 在用户离开原分享窗口并稳定500ms后释放旧的界面观察；超时状态也会在新触发前清理。这不等于确认成功，也不会取消底层系统传输或删除未确认截图。
- 连续两次实体 NFC：第一次进入相册原图分支并发送，用户确认收图；用户离开原分享窗口后旧观察释放。第二次成功进入截图分支，电脑收到截图，日志确认成功状态、返回请求和本次私有 PNG 删除成功。
- 随后用户按断开 USB/调试连接的测试提示反馈“没什么问题”；这是用户实测反馈，不包含断开期间的诊断日志。

**已确认：** 实体贴纸能启动应用；原图与截图可发送；旧观察不再阻塞连续触发；本轮截图成功后返回并删除手机临时文件，电脑文件保留。

**仍需区分：** 原图路径最近一次没有捕获到成功状态，不能宣称原图每次都能自动返回。其他手机、其他语言、其他版本、NTAG215/216标签未逐项验证。

## 2026-10-16 · v8～v10

- v8 验证截图成功后返回桌面、删除本次私有截图。
- v9 修复相册 Flutter 根节点空矩形导致选图判断失败的问题。
- v10 修复页面刷新不断延后轮询的问题；该轮多图发送后成功返回相册。

这些版本的 ADB 测试不能单独证明实体 NFC 可用，实体结果以2026-10-19记录为准。
