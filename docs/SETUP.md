# 非小米台式机与小米手机配置教程

[返回首页](../README.md) · [继续设备适配](ADAPTATION.md)

目标：不用本项目自动点击、不用 NFC，先在手机相册选择一张图片，通过小米系统分享发送到电脑，并找到收到的文件。这一步成功，才具备安装本项目进行自动化的基础。

**本教程面向非小米 Windows 台式机 / 组装机。** 小米/REDMI 笔记本已支持官方互联及一碰传时，使用原生功能即可，不需要安装本项目。并非所有小米笔记本都有相同硬件能力，具体支持情况查看官方列表。

**本步骤不需要 USB 调试、ADB、NFC 贴纸或电脑 NFC 读卡器。** 后续源码适配和诊断才可能需要 ADB。

下载入口与官方说明核对日期：**2026-10-16**。官网版本会变，优先以产品页当前显示的版本条件为准；本项目没有对每个新版重新做兼容认证。

## 1. 你的电脑该下载哪个软件？

| 电脑类型 | 优先使用 | 下载/帮助入口 |
| --- | --- | --- |
| **非小米 Windows 台式机 / 组装机（本教程对象）** | **小米互联服务 Windows 版** | [小米 Windows 互联官方页面](https://hyperos.mi.com/continuity/abilities/ab0019) |
| 小米 / REDMI 笔记本 | 不跟随本项目配置，优先使用已支持的原生功能 | [小米电脑管家官方下载与支持列表](https://pc.mi.com/pc-manager-help) |
| 其他品牌 Windows 笔记本 | 额外适配，不作为本教程主要对象 | [设备适配边界](ADAPTATION.md) |
| Mac | 本项目当前没有验证这条自动化接收路径；先参阅官方功能说明再单独适配 | [小米苹果互联官方说明](https://hyperos.mi.com/continuity/abilities/ab0016) |
| Linux、其他系统或不在支持条件内的设备 | 目前没有本项目已验证的直接配置步骤 | 先按[适配指南](ADAPTATION.md)评估，不要照搬 Windows 安装包 |

**“小米互联服务”和“小米电脑管家”不是同一个软件。** Windows 通用版页面明确将小米/Redmi 笔记本排除在它的适用范围之外；对应笔记本应先查看电脑管家支持列表。不要为了复现教程安装网上的机型绕过补丁。

## 2. 非小米 Windows 台式机：下载安装

1. 在电脑浏览器打开[小米 Windows 互联官方页面](https://hyperos.mi.com/continuity/abilities/ab0019)。
2. 页面当前有 **“下载 Windows 版”** 和 **“下载 Windows 内测版”** 两个按钮。根据手机系统及页面说明选择，不能只因“内测版”听起来更新就选它。
3. 本项目原有实测环境使用 Windows 11、HyperOS 3 和电脑端 **小米互联服务 1.1.2.36**。官网本次核对时，“下载 Windows 版”按钮仍指向这一版本。可直接使用该[官网按钮对应安装包](https://cdn.cnbj1.fds.api.mi-img.com/ota-packages/QKTo_PcContinuity_hotfix_88a510d20d_1.1.2.36_d887cad6.exe)；如失效或官网已变，以产品页按钮为准。
4. 官网将普通 Windows 版列为 Windows 11 及以上、手机 HyperOS 3 Beta 及以上的路径；内测版要求手机/平板 HyperOS 4 及以上。官网还单列了新版 AI 功能的 Windows 10 和应用版本要求，**不要把 AI 功能的条件直接套成旧版 1.1.2.36 的安装条件**。Windows 10 用户先核对当前下载分支，不保证旧版本可用。
5. 下载后，在 Windows 资源管理器右击安装包 → **属性 → 数字签名**，检查是否存在有效的小米相关发布者签名。如果提示签名无效或来源不明，先停止并核对来源。不要通过关闭系统防护来强行安装。
6. 双击安装包，按照向导安装。遇到 Windows 权限提示时核对发布者。完成后，从开始菜单搜索并打开 **小米互联服务**。
7. 如果要求登录，使用手机正在使用的小米账号登录。不要将密码、短信验证码或登录令牌交给 Agent；在官方窗口自行完成。
8. 先保持电脑端窗口打开。不要立即退出、让电脑休眠或只关闭到托盘却不确认它是否仍运行。若提示更新，记录原版本和新版本，再按软件内置更新流程处理。

此处的安装界面、登录方式和按钮位置可能随版本改变，以实际软件为准。不要把其他人的电脑设备名、MAC 地址或接收目录照抄到自己的电脑。

## 3. 台式机上的“我的笔记本”是什么？

这是作者测试时，系统分享面板给目标台式机显示的名称，不是硬件要求。你自己的电脑可能显示其他名称，后续必须据实适配，不能因为菜单写“笔记本”就认为台式机无法使用。

本项目的台式机路径使用 **小米互联服务 Windows 版**，不要求安装“小米电脑管家”，也不要求给显示器或机箱安装 NFC 读卡器。小米笔记本原生一碰功能不在本教程范围内。

## 4. 电脑网络与蓝牙准备

以下是便于初次排查的准备方式；不能把“有某款网卡”当作一定兼容的证明。

- **打开蓝牙**：Windows 11 → 设置 → 蓝牙和其他设备 → 蓝牙。没有蓝牙开关时，先检查设备管理器和电脑/网卡厂商提供的驱动。
- **打开 WLAN/Wi-Fi**：Windows → 设置 → 网络和 Internet → Wi-Fi。初次测试时，手机与电脑优先接入同一个常用 Wi-Fi，保持设备靠近。5 GHz 可在双方支持时尝试，不是强制条件。
- **台式机只有网线时**：网线和手机 Wi-Fi 接同一路由器通常可处于同一局域网，但这不等于能满足接收软件所有无线硬件要求。官方互传说明要求 WLAN 和蓝牙开启；缺少无线硬件时先检查软件提示和厂商支持，不承诺任意 USB 小网卡都有效。
- 不使用访客 Wi-Fi、带客户端隔离的网络或需要网页认证的公共网络做首次验证；它们可能阻止设备互相发现。
- 如果 Windows 弹出该应用的网络访问确认，核对应用来源，并只允许在自己信任的网络上按需通信。不要直接关闭整个防火墙。
- 开着代理/VPN 时先查看是否允许本地局域网访问。手动传图能成功就无需改它；失败也不能未经检查直接认定是 VPN。

## 5. 手机端逐项设置

1. 打开 **设置 → 我的设备 / 关于手机**，记录手机型号和 HyperOS/MIUI 版本。不同地区和版本的菜单可能不同。
2. 在设置顶部的小米账号入口确认账号。走同账号互联时，与电脑端使用同一账号；同账号自动接收能力仍取决于设备及软件支持。
3. 打开手机 **WLAN** 与 **蓝牙**，连接前述网络，保持手机解锁、亮屏并靠近电脑。
4. 打开 **设置 → 设备互联**。部分版本名称为 **互联互通 / 小米互联互通**；找不到时在设置搜索框输入这些名称。
5. 开启 **设备互联 / 互联互通服务** 总开关。若有首次协议和权限确认，请阅读并自行确认必要项。
6. 从屏幕顶部下拉控制中心，查找 **小米互传**，若有该开关则开启。没有显示时，可先用控制中心的编辑功能查找，或在设置搜索“小米互传”；不能据此假定系统一定具备本项目所需功能。
7. 若要额外测试电脑操作手机，才开启 **设备互联 → 妙享桌面**。**发送图片的验收并不要求一直开着投屏窗口**；不要把“投屏成功”当作相册发送已经成功。
8. 进入系统应用更新或小米应用商店，检查相册、互传及相关互联系统组件是否有官方更新。普通 Windows 版官方页面还引导用户前往小米社区安装“小米互传”；如果当前相册已经能发现电脑并手动发图，不要为了教程重复侧载或降级系统组件。缺失时从该[官方功能页](https://hyperos.mi.com/continuity/abilities/ab0019)的当前指引继续，不采用来历不明的 APK。

**不要要求所有读者安装作者手机的系统组件版本。** 系统服务可能有签名、地区和设备依赖，升级入口及支持范围以本机官方渠道为准。没有对应互联开关时，先回到[适配指南](ADAPTATION.md)确认支持条件。

## 6. 首次发现和连接

1. 电脑端保持“小米互联服务”或电脑管家互联界面运行，手机解锁。
2. 等待附近设备出现；如果电脑端列出手机，按它提供的连接入口继续。若手机分享面板已能直接发现电脑，也可从下一节的手动发送开始，**不要求每个版本都有一个叫“配对”的按钮**。
3. 设备若显示验证码、信任此设备、允许连接或接收请求，只确认自己正在操作的手机与电脑，按两端提示完成。
4. 没有可发现设备时，先按第 8 节排查。不要在 Windows 蓝牙设置中随便配对一个同名设备来代替软件内的实际发现测试。
5. 首次接收可能需要在电脑点击接收；具备条件的同账号设备可能自动接收。请以电脑真实出现文件为准。

## 7. 手动发送一张，再发送三张

### 发送一张

1. 在电脑新建一个空的测试接收记录，或记下当前接收目录已有文件，避免把旧文件算成本次收到。
2. 手机上打开系统 **相册**，回到缩略图列表，长按并勾选一张不敏感的测试照片。确认选中计数为 1。
3. 点击底部 **分享 / 发送**。
4. 在系统分享面板的附近设备区域找到目标电脑。设备栏通常在微信等应用分享图标的上方；名称以你自己的电脑为准，不一定叫“我的笔记本”。
5. 点击该电脑图标。电脑要求接收时自行确认，等待手机目标设备状态显示完成。
6. 在电脑接收通知、传输记录或应用提供的打开文件入口查看收到的图片。若软件设置中提供接收位置，记录该位置。**本教程不假定所有电脑都保存到同一个 Downloads 目录**。
7. 打开收到的图片确认内容，核对本轮新增文件数量为 1。界面显示“连接成功”但没有文件，不算通过。

### 再发送三张

回到相册勾选 3 张普通图片，重复上述步骤。电脑应新增这 3 张对应文件；注意同名文件可能自动加编号，其他设备同时传入也会影响数量。必要时用文件大小、内容或哈希核对。

### 记录给 Agent 的四项信息

```text
电脑端软件名称与版本：
手机型号与系统版本：
系统分享面板实际显示的电脑名称：
手动发送1张/3张的结果及接收目录：
```

如果设备名不是“我的笔记本”，这不是错误；后续需要 Agent 修改本项目 `NativeTarget.java` 里的精确名称匹配，并重新编译。当前 APK 不会自动适配所有电脑名称。

完成上述验收后，回到[README 使用前准备](../README.md#使用前准备)安装本项目，再进行无障碍授权、自动发送和 NFC 测试。手动分享后仍停在分享面板可能是系统正常行为；自动返回是本项目额外实现的功能。

## 8. 按现象排查

| 现象 | 检查顺序 |
| --- | --- |
| 安装包提示不支持此电脑 | 是否选错电脑管家/Windows通用版；系统版本、架构及官网支持范围；不强行打机型补丁 |
| 电脑没有蓝牙或Wi-Fi开关 | 检查硬件是否存在、设备管理器状态和厂商驱动；先不要购买声称“通用一碰传”的读卡器 |
| 手机里没有设备互联/小米互传 | 核对系统地区、版本、官方功能页和官方组件更新；不要随意替换系统签名组件 |
| 电脑客户端搜不到手机 | 客户端运行、账号、两端蓝牙/WLAN、同局域网、解锁亮屏、距离，再检查网络隔离及软件提示 |
| 能看到电脑但发送失败 | 确认电脑未休眠、未退出接收服务；首次接收许可、网络权限、剩余磁盘空间及客户端报错 |
| 妙享桌面能用，图片却发不出 | 单独从相册分享测试；两者入口不同，不能互相作为成功证据 |
| 手机显示完成但找不到文件 | 从电脑接收通知或软件设置查实际接收目录；看同名文件重命名，核对时间与数量 |
| 只有代理/VPN开启时失败 | 对比本地路由与局域网访问规则，仅针对已确认原因修改；不默认关闭全部安全功能 |

向 Agent 反馈时提供上面的四项信息和必要错误提示即可；不要发送密码、验证码、整份相册或未脱敏的全部系统日志。
